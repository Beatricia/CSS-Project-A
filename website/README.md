# CSS-Project-A Website

Frontend application for exploring artist geography, migration patterns, pageviews, and lyrics sentiment outputs generated by the project.

## Requirements

- Node.js 20+
- npm 10+

## Install

From this folder:

```bash
npm install
```

## Run Locally

Start development server:

```bash
npm run dev
```

Build production assets:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Run lint checks:

```bash
npm run lint
```

## GitHub Pages

- Production base path is configured in `vite.config.js`.
- The repository workflow `.github/workflows/deploy.yml` builds this app from `website/` and deploys the generated `dist/` folder to GitHub Pages on pushes to `main`.

Optional manual deploy (if you are using the `gh-pages` package route):

```bash
npm run deploy
```

## Data Notes

- Static CSV/map assets are served from `public/data/` and `public/maps/`.
- Regenerate upstream data with the Python scripts in the repository root before publishing if source datasets change.
